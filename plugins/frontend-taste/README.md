# Frontend Taste (`v2.3.0`)

The definitive anti-slop frontend engineering plugin for Antigravity, curated to permanently eradicate generic AI templates, purple gradient meshes, Inter-font monotony, boolean prop proliferation, and janky transitions.

This plugin bundles **24 official, battle-tested community skills (over 7M+ total installs)** from the world's premier creators (Anthropic, Vercel Labs, Emil Kowalski, Paul Bakaus, Leonxlnx, NextLevelBuilder).

## 2. Architecture & Zero Duplication

All 24 skills reside exclusively within this plugin and are never duplicated into the global `~/.gemini/config/skills/` directory, ensuring zero token bloat in the model's breakdown.

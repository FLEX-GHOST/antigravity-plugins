# Exa Search Plugin for Antigravity

Exa is an AI-native search and content retrieval engine built specifically for LLMs and autonomous agents. Unlike traditional keyword search engines, Exa understands semantic queries, extracts clean Markdown content from any URL, and runs multi-step autonomous research agents.

## What's Included

- **MCP Server** — Connects Antigravity to Exa's semantic search (`web_search_exa`), clean URL content extraction (`web_fetch_exa`), and autonomous deep research agent (`agent_run`)
- **Skills (5 Included)**:
  - `exa-search` — Precision semantic web search with domain, category, and freshness filters
  - `exa-contents` — High-fidelity full-text, highlights, and subpage extraction from target URLs
  - `build-with-exa` — Architect applications and agent pipelines using Exa APIs and SDKs
  - `company-research` — Deep competitor analysis, financials, news, and organizational intelligence
  - `lead-generation` — Automated ICP discovery, signal enrichment, and structured prospect lists

## Available Tools

### web_search_exa
Performs semantic and neural web searches with real-time content extraction.

### web_fetch_exa
Crawls and extracts clean, LLM-ready Markdown text and metadata from one or more URLs.

### agent_run
Dispatches an autonomous multi-step research agent to investigate complex topics and synthesize verified citations.

# حزمة إضافات Antigravity الاحترافية (Portable Plugins Bundle)

تحتوي هذه الحزمة على الإضافات الـ 5 الكاملة مع الأيقونات الرسمية، ملفات التوثيق (`Overview / README.md`)، نظام الحسابات (`auth.json` بنمط `API_KEY` بدون `OAuth`)، وجميع الـ **Skills الرسمية** الخاصة بكل أداة:

1. **Context7 (`v2.0.0`)** — جلب التوثيقات البرمجية المحدثة (بدون OAuth، يعمل محلياً مع دعم `CONTEXT7_API_KEY`).
2. **REA — Reverse Engineer Anything (`v2.0.0`)** — الهندسة العكسية الشاملة (229 أداة + 5 Skills رسمية).
3. **Exa Search (`v2.0.0`)** — البحث الدلالي الذكي واستخراج المحتوى (3 أدوات + 5 Skills رسمية).
4. **Snyk Security (`v2.0.0`)** — فحص الثغرات الأمنية في الكود والمكتبات والحاويات (15 أداة + Skill رسمية).
5. **Serena Code Agent (`v2.0.0`)** — التنقل الدلالي بالكود وإعادة الهيكلة عبر LSP (25 أداة + Skill رسمية).

---

## 1. عزل المفاتيح (`keys/keys.json`)

جميع مفاتيح الـ API معزولة تماماً داخل مجلد مستقل في `keys/keys.json` وهي فارغة افتراضياً:

```json
{
  "CONTEXT7_API_KEY": "",
  "EXA_API_KEY": "",
  "SNYK_TOKEN": ""
}
```

لا توجد أي مفاتيح أو مسارات خاصة بجهاز معين داخل مجلد `plugins/`. عند تشغيل سكربت التثبيت، يقوم السكربت بقراءة `keys/keys.json` واكتشاف مسارات النظام تلقائياً وحقنها في المكان الصحيح.

---

## 2. طريقة التثبيت على أي جهاز Windows

1. ضع مفاتيحك داخل `keys/keys.json` (أو اتركها فارغة وأدخلها لاحقاً من واجهة البرنامج عبر تبويبة `Accounts`).
2. اضغط مرتين على الملف **`install.bat`** (أو شغّل `.\install.ps1` من PowerShell).

---

## 3. طريقة التثبيت على سيرفر Linux / VPS أو macOS

1. ارفع المجلد إلى السيرفر وضع مفاتيحك داخل `keys/keys.json`.
2. نفّذ الأمر التالي في التيرمنال:

```bash
chmod +x install.sh && ./install.sh
```
